# Exercise-tracker

This is a full stack project of mine

The goal of the program is to track weightroom workouts 

The tech stack is react and typescript

To watch it in action before it has been deployed please click on the mp4 in the root folder. 

I am also using the prisma orm, jwt tokens, and zod for validation. Frontend libaries are tbd but most likeley recharts and router will be the only 2 I can see needing currently. I used vite as the bundler and I am using neon db to host the postgressSQL database. Motivation is the current tracker I use doesnt let you freely track progression while also giving statistics.
